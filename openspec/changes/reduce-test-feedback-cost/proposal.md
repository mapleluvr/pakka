# 降低测试反馈成本

## Why

2026-11-10 的交接调查显示：938 项回归约 34 分钟，CLI maintenance 约 16 分钟；默认入口收集所有文件且串行，追加路径仍不能排除其他文件。用户要求阅读交接并尝试缓解测试压力。

## What Changes

采用默认核心、人工影响域、源码发布集合和精确文件入口；隔离每次运行和文件的可变目录，保存选择范围、进度、真实退出和资源记录。审计维护测试，合并重复 fixture、下沉文件/SQLite 条件，删除由更强场景完整覆盖的重复损坏用例。保留真实进程故障、CLI 接线、records-only 与独立安装消费。

## Impact

只改变测试、runner 和开发说明。基础库/协议的影响域保守扩大到源码发布集合。实际安装继续单独选用；本轮不运行无改动产品的全仓及37阶段安装。原始证据本地保全。分支依赖已 fetch 核实的 PR #10 提交 88a0e2c；dev 为8798fe7，#10尚未合并。
