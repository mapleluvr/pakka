# Clarify product documentation

## Why

用户要求整个文档系统的产物层具有 state-evo 意义下的独立性。审查 d8f897d 及未提交指南发现：手册以开发阶段与验收经过定义接口，存储／导航说明仍有旧路径，采用规格与补丁脚本默认版本存在差距。

## What Changes

- 按当前对象、操作和适用条件修订长期手册与规则入口，保留真实权限及未知效果边界。
- 对齐 SQLite、分页、新建与设置操作说明；当前契约通过主规格及明确映射可达。
- 已完成 SQLite change 依既有生命周期归档并归并主规格；当前引用随归档同步。
- 构建／校验补丁时省略版本参数，按 agent 的精确生产依赖选版本；显式版本继续支持固定基线重建。
- 历史事实由已有记录及固定 Git 版本承接，逐项记录修订与实际检查。

## Impact

受影响产物为 README/AGENTS、docs/state、guides/reference/development、集成／补丁使用说明和主规格。补丁源码、构建锁与已验证安装包字节保持原身份。依据为用户要求、当前公开类型、生产依赖与审查记录；本次不凭文档整理扩展运行能力。
