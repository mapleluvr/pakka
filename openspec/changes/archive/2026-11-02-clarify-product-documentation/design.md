# Design

## 依据与采用

用户明确要求产物层不含阶段／验收含义。初步审查只读核对 73 个文件，发现既有历史叙述，也有当前说明矛盾。原文可从 d8f897d 的相应路径重读；近期 workflow 指南属于保留的未提交工作。

## 正文的职责

当前说明围绕对象、接口、操作和条件展开。支持条件直接维护在手册／规格中，不能仅指向某次 accepted with notes。M/P 开发阶段、复审修复经过、检查计数和后续安排回到已有形成与固定记录。版本、hash、许可、P1–P4 产物名和 accepted/unknown 等运行语义按其用途保留。

使用指南以当前采用界面和公开接口核对步骤。目录导航指向可独立使用的契约；OVERVIEW 和 tasks 承接当前工作。原验证记录与追加账本保留，不为文风改写固定结论。

## 规格归并

SQLite change 已实施并完成选定检查，按 OpenSpec archive 同步主规格，消除 legacy migration requirement 与 SQLite delta 的重复阅读。引用更新到归档位置和生成的主规格。尚在设计／实施中的 change 不随文档清理归档。

主规格的纯编辑修订由本 change 的 MODIFIED delta 保存形成记录，并通过正常归档同步；其运行条件与支持边界保持原含义。

## 默认补丁版本

生产选择归 packages/agent/package.json 的固定 Durable file dependency。构建与完整性校验共用一个解析函数，从该精确文件名读取版本；格式不确定时拒绝。显式版本仍经既有语法验证并对应版本目录。回归从临时仓库布局运行真实脚本：校验默认产物、上游基线匹配、显式旧版本及默认产物篡改拒绝。构建探针在网络／安装之前有界停止，避免重建既有归档。

## 历史与结果归属

已有验收／验证文档和固定配对保存其原范围。长期入口只给用途与身份导航；检查数字、历史失败或修复过程保留原记录。临时审查不作为唯一长期依据：本 change 保存发现类型、决策和实际结果，并链接有关主规格／形成记录。
