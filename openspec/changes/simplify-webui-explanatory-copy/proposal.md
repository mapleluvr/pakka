## Why

用户指出首页 `Send work only after the Conversation is ready.` 多余，并在全仓静态调查后授权执行推荐的精简方案。工作台和扩展的常驻文案重复字段/按钮、解释后台保证，部分长说明是在补偿含混的名称；重要状态与实际后果需要保留在相关操作处。

## What Changes

- 采用调查 D1–D13：移除首页、创建/模型/文件夹、Files、审批、设置和通知的重复教学及已确认消息中的自我担保尾句。
- 采用 Q1–Q8 的推荐形式：服务器位置/本机保存用短标签；人类聊天和笔记明确命名；Session 密钥短作用域、额度和 Webhook 接入信息按需展开；语音服务只在使用时说明。
- 用准确名称呈现定时输入的提交结果；归档、扩展 UI 禁用及 worktree 的后果在实际动作反馈。Memory 沿用全局/项目与待批准标记。
- 保留原请求、unknown/冲突/部分成功、拒绝、截断、秘密和不可逆后果。无后端协议、权限、调度或持久化变更，不建立额外产品实体。

## Capabilities

### New Capabilities

- `devin-frontend`: 在尚未归档的同名前端谱系追加简洁、情境化 UI 文案与明确人类聊天/输入提交名称的可观察要求。对应主 spec 随前置活动变更归档后再合入，不抢先生成残缺主 spec。

### Modified Capabilities

无已归档的对应主 spec。

## Impact

`apps/webui/web`、六个内置贡献及实际 browser 回归；现有 CSS/原生 details 和状态渠道承接必要信息，无新依赖。前一菜单/创建入口 change 保持独立记录，最终候选一起重跑受影响和全量门禁。调查原文及 source manifest 保留，采用记录、状态和本地计划同步更新。
