# Adopt frontend guides and native Devin behavior references

## Why

The operator selected Atlassian Applying typography and Vercel Web Interface Guidelines as ongoing pakka-webui development guides, and the offline Devin production frontend as the absolute reference for corresponding native UI behavior. The current reference hierarchy names the visual prototype without giving the production dump this explicit authority.

## What Changes

- Preserve usable guide material with source identity, version and license information.
- Map production bundles, captured DOM and readable extracts to their distinct evidence roles; use native behavior as the decisive UI reference.
- Introduce relative typography roles in configuration, readable mobile fields and visible composer keyboard focus while preserving native service semantics.
- Keep further navigation, form, transcript and responsive differences in an actionable comparison queue.

## Impact

Frontend state, developer entry points, appearance/CSS and browser regressions. The production Pi cohort, RPC, persistence, authorization and original request identities retain their current contracts. The pinned reference CSS remains byte-identical.
