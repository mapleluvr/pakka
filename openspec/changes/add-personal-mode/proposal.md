# 个人模式与设备

同一人在多端接续工作时，身份、成员权限和 driver 领取构成重复管理。采用共享 Person、独立可撤销登录的 personal 模式，保留 collaboration 的多人能力。预算备注改为可选。

设计与形成记录见 [change](../../../docs/changes/personal-mode.md)，采用契约见 [WebUI state](../../../docs/state/webui.md#个人模式与设备)及 [Runtime state](../../../docs/state/runtime.md)。协议/client 与服务属于 Pakka，交互属于独立 WebUI。任务见 [tasks](tasks.md)，增量规范见 [spec](specs/personal-mode/spec.md)。
