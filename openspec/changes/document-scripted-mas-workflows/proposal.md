# 用脚本编写 MAS 协作流程的指南

## Why

用户通过双 Conversation 示例确认，应用可以组合现有 Runtime、MAS 和 DevPack 能力编写 workflow，并要求以指南支持这种使用方式。指南读者也包括 Agent：制作时需要 Mermaid 可视化、从普通测试到确定性推理再到获批真实模型小任务的可行性验证，以及对实际产物和状态的持久化取舍。

现有应用指南主要覆盖 HTTP server/client/CLI 装配；可运行的 workflow 示例已使用公开接口实现双向交流、X 保存 C、双方完成与结果重开。

## What Changes

- 增加面向人和 Agent 的协作流程编程指南，连接可运行脚本、接口参考与使用导航。
- 采用 Mermaid 图、程序与角色指令、业务完成条件相互对应的编写方法。
- 说明按产物、状态、引用、提交边界和重开行为选择保存方式。
- 说明逐级验证的证据范围；Agent 主动请求具体的便宜快速真实模型试跑安排，用户批准后执行。
- 在产品和 MAS state 中直接声明应用脚本表达协作流程的能力。

## Impact

文档、使用导航及已有示例和本地确定性用例的交付。Runtime、MAS 和 DevPack 的公开接口及原生提交、权限、投递和 unknown 语义沿用现行契约。
