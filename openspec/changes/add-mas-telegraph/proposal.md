# Add Opt-in MAS Telegraph

## Why

Hosts need a portable, explicit way to ask selected MAS agents for compact reasoning and coordination while preserving full problem-solving, exact tool syntax, authority and readable human deliverables. The operator supplied a Skill draft and authorized this Worker session as a prompt-level trial. BabelTele motivates the representation style; its prompt-induced research results do not establish lossless compression, universal comprehension or lower reasoning-token/total cost for Pakka.

## What Changes

- Ship versioned `mas-telegraph/SKILL.md` in the MAS DevPack archive through a public file export, with explicit invocation and no global installation.
- Add independent, default-off `telegraph.reasoning` and `telegraph.communication` options to `createMasDevPack()`.
- Select those options per approved profile through `telegraphByProfile` in the public profile composer, Server preset and private worker JSON configuration; reject malformed or unselected targets.
- Reuse the Skill's selected sections and common semantic/audience rules as the injected instructions. Preserve existing default prompts, tools, request text, profile removal and authority boundaries.
- Document actual loading, A2A intent, final-reader rules and focused validation.

## Impact

`@pakka/mas-devpack`, Server bootstrap/worker configuration, their existing deterministic regressions and archive consumers. No Runtime, MAS ledger, Durable patch, frontend settings, protocol or new package is introduced. Independent review and final acceptance remain with the parent; remote writes are outside this implementation task.
