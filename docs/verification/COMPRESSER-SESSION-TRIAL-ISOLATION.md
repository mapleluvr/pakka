## Defect, boundary and evidence

A tool schema diagnostic can include the complete rejected candidate. The shared guard forwarded its raw last cause into source-B admission errors, late-result status, audit and failed business artifacts after source A sealed the container. The root source RED and a separate old-installed-archive RED both reproduced private synthetic source-A text in source B.

The corrected guard returns constant sealed/unavailable messages with no raw cause or nested error. Source A retains its own actual diagnostic; the identity-bound trusted bootstrap snapshot retains the full last error and originating job. The snapshot is not a conversation-scoped endpoint. This preserves the operator's last-error report while respecting external source authorization.

The new source case checks denied admission without another reservation, an already-in-flight foreign response becoming quarantined, trusted cause retention and no raw cause in the unrelated result. The new shipped Dynamite case checks source-B status, actual audit and persisted failed-run records after two external business Sessions share the container. Both use actual native storage and localhost requests, not fabricated result objects.

Selected [raw evidence](evidence/compresser-session-isolation/) includes both REDs, the source GREEN, installed observations/requests, original host full and installed logs, public declarations and dependency inventory. ## Structure and scope

There is one long-lived Compresser Session, many source-job Conversations and many external business Sessions/Conversations. One external Conversation can start several internal jobs. The shared Session owns cumulative counts/sealing; individual Conversations retain source-bound repair history across native runs. Every request remains charged/audited under its original source job.

The business store adopts one atomic run/block with P1 and a version-1 sidecar containing P2 graphs, P3 annotations, P4 clues and unresolved items. Only P1 enters later main-model projection. The first trial does not create four stores or four Conversations for the four product roles. P1 is block.text; block.artifacts stores the versioned sidecar; run stores outcome/usage/source evidence and links blockId. Independent per-layer decay and active retrieval remain unimplemented, not redefined as already satisfied by the bundle read API.

Normal reopen and fail-closed interrupted work remain verified. Operational history retention, explicit replacement/recovery after sealing, historical SQLite migration, other providers/storage and optional server assembly remain [follow-up tasks](../../openspec/changes/add-compressor-repair-session/tasks.md). No automatic uncertain-effect replay, custom agent loop, user credentials, paid models or adversarial review was used.

Current expectations are in [service state](../state/compressor-session.md), [Strategy API](../reference/STRATEGY-API.md) and [Dynamite state](../../../pakka-dynamite/docs/state/artifacts.md). Formation and all proposal/design/tasks/delta links are retained by [the change](../changes/compressor-repair-session.md). [Initial LSP disposition](evidence/compresser-session-trial/lsp-disposition.md) retains its limited scope; the separate active probe checked three changed source/test files: two confirmed clean, one push-only/silent-on-clean result inconclusive, zero reported errors.
