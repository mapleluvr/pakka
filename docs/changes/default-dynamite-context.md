# 默认 Dynamite 上下文

2026-11-07 用户选择普通 Pakka 产品默认启用 pakka-dynamite。采用范围是 `pakka` 产品装配；独立 SDK/headless 的宿主选择及旧固定配对保持各自契约。默认配置接入尚未实现。

- 完整记录：[change](../../openspec/changes/adopt-default-dynamite-context/)、[proposal](../../openspec/changes/adopt-default-dynamite-context/proposal.md)、[design](../../openspec/changes/adopt-default-dynamite-context/design.md)、[tasks](../../openspec/changes/adopt-default-dynamite-context/tasks.md)。
- 全部 delta：[default-product-context](../../openspec/changes/adopt-default-dynamite-context/specs/default-product-context/spec.md)。该 capability 尚无已归档主 spec。
- 相关主规范：[dynamite-persistence](../../openspec/specs/dynamite-persistence/spec.md)、[conversation-runtime](../../openspec/specs/conversation-runtime/spec.md)、[optional-dynamite-product](../../openspec/specs/optional-dynamite-product/spec.md)。旧 headless 可选贡献的固定支持范围没有由本 change 扩大。
- 当前声明：[产品](../state/product.md)、[Compresser](../state/compressor-session.md)、[Dynamite 持久化](../state/dynamite-persistence.md)。

同轮还追溯了 512 投递与 32 在途 HTTP 的来源；历史依据和候选要求保存在 design，未将其候选改造作为已采用产品规格。
