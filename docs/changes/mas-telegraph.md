# MAS Telegraph

采用显式启用的紧凑 reasoning 与 inter-agent communication 提示。宿主分别选择两个开关，按批准 profile 装配；共同规则保护完整分析、语义锚点、A2A 意图与面向人的可读产物。版本化 Skill 随 DevPack 归档提供公开路径，并作为注入提示的唯一正文来源。BabelTele 提供表达方式的启发，本实现不宣称无损或 token/费用收益。
