# History Book 与 Historian

History Book 是 Dynamite 的版本化史料产物。Dynamite 提供独立的查询、展开、编辑、补注、版本和回执服务，普通 Agent 通过受权工具直接使用。Historian 按获准来源的已提交局部产物异步接续，形成 Book 新版本。

## 服务与持久身份

每个业务 Session/Conversation/产物 namespace 对应稳定 Book 身份。Book、版本化图页、输入引用、编辑记录、工作进度与发布回执保存在原业务 SQLite，由宿主 writer 通过公开事务提交。原文、局部 P2/P3/P4、Book 及后来补注各自保留版本与来源。

Historian 是显式启用的长期服务 Session；每个有限合并任务使用独立原生 Conversation，保存完整修复轨迹、计数、seal、固定结果及费用。每个 Book 的自动合并串行，不同 Book 可并行。宿主保有原生可变对象；Dynamite 接收固定 DTO 和身份绑定命令。

Book 的读写可在 Historian 停止时独立使用。读写服务只执行本次获准存储操作；后台生成由独立执行入口和预算控制。模型调用的授权与调用者编辑权分别检查。

## 内容与编辑

Book 以有界章节、节点、边、综合注释、线索和未决项组织材料。局部来源 ID 命名空间化；关系保留来源引用、观察范围和不确定性。相同标签或相邻时间只用于候选定位，语义同一与因果关系由所引证据支持。

编辑携带稳定 requestId、baseRevision、有界变更和依据。服务绑定操作者，重新检查授权、版本与引用，将版本根、变更事实和回执原子提交。修订与补注可回看；原局部产物持续保留。Historian 采纳还须核验精确原执行回执，普通编辑凭独立编辑授权提交。

版本 CAS 使竞争编辑明确冲突；迟到候选保留原身份和费用，重新规划以最新已确认版本为基础。普通编辑不推进自动摄取进度。补注有独立版本水位，读取将 Book 版本与补注水位固定成组合视图，已保存正文与引用按 Book 对象授权，不因引用目标的读权变化联动失效。补注事务身份包含 Book、操作者和原请求，不同 Book 可独立接受相同的本地请求 ID。

## 分页与来源权限

目录、变化流、图页、历史与工作项按固定上界分页；正文按需读取，预算以完整编码后的响应计算。版本根引用不可变索引页，写入只创建受影响路径。查询旧版本直接定位其根，运行缓存和活跃工作有界，累计历史独立增长。来源倒排索引也使用每版不可变根；按精确原始 entry/contentVersion 定位共享史料，再读取有界候选。共享来源只说明材料重叠，不授予节点同一或因果关系。候选查询可跨来源键重复返回实体 ID，消费者按稳定 ID 去重。

固定引用包含 storage/Session/Conversation/namespace、产物版本、来源 entry/contentVersion/hash。读取区分当时完整性、当前适用状态和当前授权；旧有效版本不可得时明确返回 unavailable。原始 entry 读取使用原 archive 的消息和固定 fingerprint，逐次核验；当前投影后来编辑过的内容不会替换原引用。未被原 archive 保存的 effective 版本及超过单对象读取预算的内容明确不可得。Book 正文、图结构与已保存引用使用 Book 自身授权，不因引用关系自动继承目标资料读权或可用性；真正回源读取 artifact/原文才核验目标、固定版本及当前权限。公共异步返回层在最后一次 await 后同步复查实际读取对象自身授权。`checkPublication(result)` 以同一 Client 的原冻结结果绑定原操作权限与固定引用；复制、重建或其他 Client 的对象返回 invalid。空回执使用该 Client 已取得的回执查询授权。绑定使用弱键，校验只保存规范化引用字段与权限检查，不另存正文或形成累计结果缓存。原生工具在 dispatch 和 Promise.race 之后同步核验 invocation 与原结果，再序列化；读取失权返回 denied，已提交编辑或补注的发布失权保留 unknown 和原回执核对。

游标绑定对象、版本、查询和身份。`checkEvidence(refs)` 同步复查 Book 当前读权及至多 64 个实际解析、读取的来源对象；空数组只检查 Book 自身读权。它不读取正文、不提交事务，也不授予执行资格。普通 Book 页不为下游格式重读实体或筛掉原样引用。下游若需要格式转换、分层导航与更小响应预算，通过公开 Book 能力在自身适配层实现。

## 摄取、恢复与停机

已采纳局部产物的持久序列是摄取依据，通知用于唤醒。开启时保存起始位置并补扫，低频 head 检查弥补通知丢失；首次启用默认处理后续产物。显式回填固定范围和预算；pause 保留原区间并允许追赶，disable 结束该区间。重开恢复数据，执行由当前授权显式启动并受恢复停机门约束。

固定 plan 在调用前提交，包含输入区间、Book base、读取集、策略与预算。通过独立 attempt 身份和 lane CAS 取得本次执行资格；原幂等回执只证明已提交事实。每次外部请求先持久预约。有限修复保留原请求、计数和上下文。

业务版本、消费 checkpoint、精确结果采纳回执、已消费 bundle 指纹和工作完成事实原子发表。重复出现的完整相同 bundle 推进输入位置而不再请求模型；来源与正文不同的产物仍是独立输入。P1-only 产物记录输入区间但不调用记史模型。两个存储域按原工作/请求/结果身份核对：已有封存结果仅做本地补记；接纳或结果未知时隔离原工作与预算，等待核对。管理者明确跳过时保存缺口，保留原执行结果与已消耗额度，先提交业务处置，再按原身份退出原生活跃索引；丢响应后可继续这一核对。未知执行不允许换新工作重发；只有已知完成/失败的候选可由管理者显式 rebase 到新的 Book 版本。退休与发表是持久终态，迟到恢复写回保留当前终态；退休工作只能继续核对目录退出，不能再次发表。每次执行在第一个异步读取前建立执行 epoch 与取消信号；停止先撤销该执行，再结算或隔离已发工作，最后关闭 writer。原生 Historian 的请求级 provider 与 extension 在初始化失败和执行完成后均释放，共享服务 Session 的持久记录继续保留。

## Memo 复用

Memo 通过 Patchouli 研究 Dynamite 产物，将形成的知识保存到独立 Memo DB（图书馆），保留固定史料引用及书库权限。来源 provider 位于 `@pakka/memo/dynamite`，消费 Dynamite 公开 Book 服务；图书馆身份、share 策略、格式转换和来源导航归 Memo 管理，Dynamite 不反向提供 Memo 专属入口。登记来源不授予读权。Patchouli 对 Book 的编辑调用 Dynamite 服务，对图书馆的发表调用 Memo 服务，两者分别确认。

宿主提供分页产物端口、固定历史读取集授权、受控原生 Historian 执行和原子发表能力；Dynamite 持有 Book 领域模型，Memo 持有图书馆知识。原生对象仍封装在 durable adapter 中。
