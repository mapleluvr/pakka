# 交付与验证

## 产物与身份

交付物是可通过公开入口在仓库外安装和使用的包/应用。版本、公开 exports、批准的 Pi cohort、下游 Durable artifact、原始来源与资产许可证均可核对；安装消费者通过所交付归档和声明依赖运行。

固定候选包含实际源码、必要的未提交/未跟踪文件、构建和门禁 helper、交付资产。构建与安装以身份 preflight 通过为前提：源码完整，归档可读且内容身份匹配，lock 与实际安装消费者对应。

日志、截图、receipts/存储及摘要绑定候选版本、环境和验证范围。长期支撑结论的依据保存在接手者可持续获取的位置。

## 门禁与证据

| 门禁       | 成立条件                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------- |
| 源码与类型 | 相关 check/build/语法、受影响回归和全量结果分别保存                                       |
| 行为与权限 | 实际服务的正向动作、真实结果/拒绝、效果时撤权、原请求核对、private canary 及请求/效果计数 |
| 前端符合性 | 相同实际 viewport 的候选与参考、直接看图、结构/几何和完整差图                             |
| 仓库外安装 | 实际归档、独立于根 workspace/overrides 的消费者、公开声明、executable/资产和浏览器操作    |
| 独立 GUI   | 固定候选、独立 worktree、唯一 agent-workspace-linux desktop、指定模型和真实 Computer Use  |
| 独立审查   | 指定 adversarial-review 工作流、双方意见/争议及作者 closing                               |
| 远程/设备  | 实际 TLS/proxy、人员/设备和部署身份，以及目标设备上的显示与操作结果                       |

各门禁分别形成结论，完整交付以全部必需项在同一候选上满足条件为前提。本地确定性浏览器回归与独立 GUI 分别按[开发契约第 9 节](../development/WEBUI-DEVELOPMENT.md#9-实际开发与验证路径)和[第 10 节](../development/WEBUI-DEVELOPMENT.md#10-分阶段-computer-use-实操验收)取证；所需环境缺失时对应门禁为 BLOCKED。

## 结果的适用条件

- 测试使用显式本地确定性 provider；账户、凭据、HOME/profile 和数据均为隔离的测试资源。
- 每项记录 PASS、FAIL、BLOCKED 或 NOT_RUN，并保留 skip/cancel/todo。必需项通过以实际执行并满足其条件为前提。
- 每个候选有自己的验证记录；历史结果用作注明版本与环境的对照。环境归因使用干净基线、相同条件和有判别力的实验。
- 接纳回执、输入持久化、generation、应用回复与工具/外部效果分别确认；业务完成结论由其对应的实际结果支持。安装结论包含真实消费者和业务操作结果，通知结论包含目标设备上的显示/操作结果。
- 源码或资产变化后，结论绑定新的候选身份及相应门禁结果；纯文档修改核对文档分工、链接/锚点、格式、差异与相关规范。

执行命令、环境设置与采集方法见[验证方法](../development/VERIFICATION.md)。独立模型、工作流和快照职责见开发契约及 AGENTS。候选结果见[实施状态](../PAKKA-POCKET-STATUS.md)。
