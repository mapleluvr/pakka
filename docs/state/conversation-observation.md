# Conversation 观察与完整内容

## 历史、执行与展示

持久历史服务于长期任务执行，完整原生记录、工具参数与发布结果按原身份保留。模型活动上下文、浏览器可见窗口与档案容量分别管理。观察或折叠展示不截断模型执行输入，不改写存档、投递回执或未完成工作的状态。

工作台冷打开不因查看目录、状态或历史预览而创建完整档案视图或装载模型执行上下文。执行和受权策略 frame 的完整语义独立保留；查看预览不表示任务恢复或重新执行。

## 有界观察

正常观察最多每 333 ms 合并发布一轮变化。状态、原资源/来源/调用身份、错误、已发布内容大小、预览和完整内容引用共同表达工具卡；已完成的相同版本不重复传正文，无变化仅小心跳或版本确认。

预览页同时按条数和字节计量。实时参数与错误也按字节、深度和访问节点计量，保留调用身份并明确展示预览；源采集的遗漏计数不能与显示截断混为一谈。摘要的读取/投影工作有界，不能在全量解码完整历史后以截断返回值宣称读取有界。原生不能提供分块或部分读取时，使用明确版本的公开接缝或可重建派生读模型；不修改已安装依赖、不把读模型当作另一份权威档案。

## 按需完整阅读

折叠卡只创建摘要 DOM，不创建完整参数、正文、Markdown 或图片。展开和进入视口后按需要读取并创建有限行/段落；离开热窗口回收节点。内容获取、缓存和 DOM 驻留分别计量，全文取完不等于全文全部渲染。

工具完整内容具有原 Session、Conversation、分叉来源、Entry/调用、字段及内容版本身份。每次详情/范围读取都校验目标可见性和有效 read 权限；等待后再次验证。旧版本、无效范围、越权、失效来源或不明结果有明确状态，不把另一资源的同号调用拼进当前卡片。

完整内容支持加载更多、明确全取和原文交付；分块连续性与版本/终态校验共同确认完整性。源采集已经截断的输出保持 source-truncated 信息，不能将本次成功读取称为丢失字节已恢复。

没有经过验证的原文引用时，实时或内联内容只具有预览范围：复制和字面搜索只作用于当前预览。预览中未匹配不能证明完整原文不存在，也不能从摘要取得全文读取/下载能力。固定原文引用可用并通过权限核验后，原文操作再按其内容版本读取。

## 缓存与空闲补取

浏览器缓存按 server/person/完整资源和内容版本分域，以字节预算/LRU 管理，普通正文不默认写入页面持久存储。虚拟窗口保持滚动、展开、焦点与匹配定位；用户仍可阅读原文和搜索/导航所选历史，不能因回收 DOM 将档案标为不存在。

空闲补取是有界的可见/展开/邻近内容补齐，一次一个分块请求，节流并受缓存预算控制。新输出、用户操作、压力、离页或撤权优先暂停/取消读取；取消浏览读取不 abort 工具或回滚任务。可选全取不隐含全档案自动复制或无限驻留。
