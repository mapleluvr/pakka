## 有意保留的可见差异

- 参考的 Ask、PR／仓库连接、额度等演示元素不进入产品。首页字段是 Conversation 名称；创建后仍需进入会话显式 Send。
- 真实人员、权限、归档／搜索、扩展导航替代演示组织和假菜单；全局控制没有为了截图相似度而隐藏。
- 独立图标按钮至少 44px，故卡片高度和工具栏不要求与静态原型的小按钮像素相同。
- 原生会话、工具／回执以及已保存字体／字号有自身内容，不用静态数据或裁切遮掉这些差异。

没有使用排除大块真实功能区域的 mask。未产生可以据此宣称“全图像素相同”的 diff heatmap／stripes；本记录也不声称存在。已知差异是产品映射的显式取舍，不包装成像素误差为零。
